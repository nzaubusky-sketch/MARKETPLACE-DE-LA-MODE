# Marketplace de la mode

Version démonstration statique, prête pour GitHub Pages.

## Mise en ligne

1. Créer un dépôt GitHub.
2. Envoyer tout le contenu de ce dossier à la racine du dépôt.
3. GitHub → Settings → Pages.
4. Source : Deploy from a branch.
5. Branch : main / root.
6. Enregistrer.
7. Ouvrir l'URL fournie par GitHub Pages.

## Important

Cette version est un prototype front-end. Les données utilisent localStorage. Le paiement est simulé. Pour une vraie marketplace multi-utilisateurs, il faudra ajouter un backend, une base de données, une authentification sécurisée et un vrai prestataire de paiement.
